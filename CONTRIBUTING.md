# Contributing

Arete is in its design phase (pre-0.1). Until version 0.1 ships:

- Bug reports and questions are welcome as issues.
- Pull requests that change syntax or semantics are not accepted yet. Every
  language decision is recorded in `SPEC.md`; open an issue to discuss one.
- Pull requests that fix typos, build problems or tests are welcome.

Code comments and documentation are in English. Every feature comes with a
test in `tests/` (a `.rt` file plus a `.expected` file with the exact output).
